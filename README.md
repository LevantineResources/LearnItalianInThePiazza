# Piazza

An RPG-style game that takes you from zero to travel-ready Italian. Walk around an Italian town, hit the
language barrier, learn from your handbook, and talk your way through it.

```bash
npm run setup     # once
npm run build     # -> dist/index.html (open it in a browser; this single file is what gets published)
npm test          # full playthroughs of every lesson
```
